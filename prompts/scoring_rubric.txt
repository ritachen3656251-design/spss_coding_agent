## 评分等级

- 0分：只有行为描述，完全没有心理状态
- 1分：描述心理状态（想法、意图、感受），但没有对物体的错误识别
- 2分：明确说出人物对物体产生了错误的物品识别/信念

---

## 补充判断规则（基于常见错误案例）

### 2分的核心标准（重点）

关键原则：2分 = 回答者理解了"人物对物体产生了错误的识别/信念"

以下表述均应判断为2分：

1. 含"以为+物品名称"
   - "以为是围巾" → 2分
   - "以为是布匹" → 2分
   - "以为是毛巾" → 2分
   - "误以为是皮草" → 2分
   - "以为是毛领子" → 2分
   规则：只要回答者说明人物把猫错误识别为某种物品，即为2分

2. 含"看错了/认错了/误认为"
   - "他看错了，以为是围脖" → 2分
   规则："看错了"等价于错误信念

3. 隐含的错误识别（无"以为"但意思相同）
   - "因为这是女人的围巾" → 隐含：他认为那是围巾（实际是猫）→ 2分
   - "他把猫当成围巾拿起来了" → 隐含：他认为是围巾 → 2分

### 1分和2分的关键区别

1分：描述心理状态，但没有对物体的错误识别
   - "他想拿给女人" → 想法/意图，非错误信念 → 1分
   - "他打算帮忙" → 意图描述 → 1分
   - "他觉得应该帮忙" → 判断/感受 → 1分
   - "因为和围脖很像" → 描述外观相似性，没说他误认 → 1分

2分：明确说出人物对猫产生了错误的物品识别
   - 含"以为是[物品]" → 2分
   - 含"误以为是[物品]" → 2分
   - 含"当成[物品]" → 2分
   - 含"看成[物品]" → 2分

### 0分的判断（避免误判）

0分：只有行为描述，完全没有心理状态
   - "不小心" → 只是行为方式，无心理信息 → 0分
   - "以为是假猫" → 知道是猫（只是真假之别），不是对物体的错误识别 → 0分
   - "以为在帮忙" → 描述意图而非对物体的错误识别 → 0分
   - "以为是东西" → 过于模糊，无法确认错误信念 → 0分

### 特殊情况处理

极短文本（少于5个字）：
   - 不要脑补，严格按字面判断
   - "不小心" → 0分（无心理信息）
   - "不知道" → 0分（无心理信息）
   - 如果确实无法判断 → 0分（保守原则）

隐含错误识别的判断标准：
   - 必须能明确推断出"人物把猫误认为某种具体物品"
   - 仅描述外观相似（"很像围巾"）不算错误信念 → 1分
   - 明确说出误认结果（"因为这是围巾"）才算 → 2分

## 判断原则补充

### 原则一：0分和1分的核心区别

0分的本质：回答者没有提及任何心理状态，只描述了行为结果、性格特征、或客观事实。

类型1：性格/品德描述 → 0分
  如：善良/热心/有爱心/懂得帮助人/出于礼貌

类型2：行为结果描述 → 0分
  如：因为他捡起来给那个妇女、因为他在帮助那个女人

类型3：外部归因 → 0分
  如：因为是顾客的、因为是这个女士掉的

1分的本质：回答者提到了人物的主观心理状态，包括想法、意图、感受、判断，但没有描述对物体本身的错误识别。

类型1：意图描述 → 1分
  如：他想帮忙、他打算捡起来给她

类型2：情感/动机描述 → 1分
  如：他认为是他弄掉的、他想要那种披肩

关键区分：性格词（善良）→ 0分；当时的意图（他想帮助她）→ 1分。

### 原则二：2分的判断不依赖特定词汇

2分的本质：回答者理解了人物对猫产生了错误的认知，不论用什么词汇表达。

方式1：直接说明错误识别
  "以为是[物品]"、"误以为是[物品]" → 2分

方式2：描述认知过程的词汇
  "没发现是真的" → 隐含以为是假的 → 2分
  "没看清是什么" + 有具体错误判断 → 2分
  "没看清" + 无具体错误判断 → 0分（信息不足）
  "粗心/不注意" → 仅描述态度，信息不足 → 0分

方式3：隐含错误识别
  能明确推断出"把猫误认为某种具体物品" → 2分
  如：人多以为是商品掉了、以为是掉下去的皮革

### 原则三：结果词汇 ≠ 信念内容

以下词汇只描述结果，不描述信念内容，打0分：
  "拿错了"、"捡错了"、"错觉"、"误会"

规则：必须说明"以为是什么"才构成2分。
  "拿错了" → 0分；"以为是围巾，结果拿错了" → 2分

### 原则四：信息量不足时的处理

极简回答（少于5个字且语义模糊）：
  "粗心"、"热心"、"错觉"、"眼睛不好" → 0分

有情景补充的回答：
  情景描述可以辅助判断。如"人多！抢购的时候以为是商品掉了" → 明确说"以为是商品" → 2分。

### 原则五：编号前缀和噪音处理

去掉编号前缀，只分析实际回答内容。
  如：Q5：他想要那种披肩 → 分析"他想要那种披肩"

只分析与题目相关部分。
  如："不注意观察。你们的问卷调查占用的时间太多了！！！" → 只分析"不注意观察" → 0分

## 示例（Few-shot Examples）

### 2分示例
回答："以为是围巾" → 2分
原因：明确说出把猫错误识别为围巾

回答："他看错了，以为是围脖" → 2分
原因："看错了"直接表明错误识别

回答："误以为猫是皮草" → 2分
原因："误以为"明确表示错误信念

回答："他把猫当成围巾拿起来了" → 2分
原因："当成"表示错误识别

回答："因为这是女人的围巾" → 2分
原因：隐含他认为那是围巾，实际是猫

### 1分示例
回答："因为和围脖很像" → 1分
原因：只描述外观相似，没说他误认了，不是错误信念

回答："他想拿给女人" → 1分
原因：描述意图，不是对物体的错误识别

回答："他打算帮忙" → 1分
原因：意图描述

回答："他觉得应该帮忙" → 1分
原因：判断/感受，非错误识别

回答："他想要那种披肩" → 1分
原因：欲望描述，未涉及对猫的误认

### 0分示例
回答："不小心" → 0分
原因：只描述行为方式，无任何心理状态信息

回答："他以为是假猫" → 0分
原因：知道是猫（只是真假之别），不符合错误信念定义

回答："以为在帮忙" → 0分
原因：描述行为意图，不是对物体的错误识别

回答："以为是东西" → 0分
原因：过于模糊，"东西"不是具体物品，无法确认错误信念

回答："拿错了" → 0分
原因：只说结果，未说以为是什么

回答："善良" → 0分
原因：性格词，非心理状态

回答："因为他在帮助那个女人" → 0分
原因：行为结果描述，无心理状态

### 易混对比（重点区分）
1分：他想拿给女人 ←→ 2分：他以为是女人的东西，想拿给女人
1分：因为和围脖很像 ←→ 2分：因为这是女人的围巾（隐含：他认为是围巾）
1分：他觉得应该帮忙 ←→ 2分：他看错了，以为是围脖
1分：他打算帮忙 ←→ 2分：他以为是围巾，想帮忙捡起来
